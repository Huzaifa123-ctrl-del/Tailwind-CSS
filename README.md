# Facebook Clone

A Facebook-inspired social media UI built with HTML, CSS, and Tailwind CSS.

## Features

- Facebook-style user interface
- Responsive design
- Navigation bar
- Post section
- Profile and social media elements
- Responsive layout using Tailwind CSS

## Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- Vite

## Project

This project was created for learning and practicing Tailwind CSS and responsive web design.
